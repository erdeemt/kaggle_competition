# Agent Instructions

All workflow rules for this repository live in [CLAUDE.md](CLAUDE.md). Read and follow that file.

Summary of the non-negotiables:
- Work only on experiment branches: `erd_exp/<name>` (Erdem, Windows) or `bet_exp/<name>` (Betül, macOS).
- Branch from latest `main`; add files into the shared file structure defined on `main`.
- Finish every experiment by pushing the branch and opening a PR — **never merge into `main`**.
